# Security Policy

## Supported version

Security fixes target the current `main` branch until versioned releases exist.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for this repository. Do not include
secrets, credentials, personal data, customer data, or business data in a public
issue, pull request, discussion, or test case.

Include the affected component, reproducible steps using synthetic data, impact,
and any suggested mitigation. Maintainers will acknowledge a complete report and
coordinate validation and disclosure through the private report.
